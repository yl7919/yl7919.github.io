Exhibit 4 — Portfolio formation under alternative factor models

From Characteristic Geometry and Portfolio Choice

What you are looking at. Six investment rules are fitted on the same monthly stock panel and turned into holdings with a common portfolio formula. The chart follows one dollar invested in each rule on a unit-gross basis. Switching the view to beta-only vs complete IAB isolates one decision inside NA-IPCA, the use of the retained intercept mean, by capitalisation universe. The ablation ladder shows, within one fitted model, how much of the gross increment comes from the mean input rather than the instability adjustment.

fmt2 = (x) => (x == null || Number.isNaN(x)) ? "n/a" : x.toFixed(2)
fmt1 = (x) => (x == null || Number.isNaN(x)) ? "n/a" : x.toFixed(1)
fmtBp = (x) => (x == null || Number.isNaN(x)) ? "> 500" : `${Math.round(x)} bp`
parseMonth = (s) => new Date(`${s}-01T00:00:00Z`)
// Sharpe, annualised, sample std (ddof = 1): matches the release convention
sharpe = (r) => {
  const n = r.length, m = r.reduce((a, b) => a + b, 0) / n
  const v = r.reduce((a, b) => a + (b - m) ** 2, 0) / (n - 1)
  const vol = Math.sqrt(v) * Math.sqrt(12)
  return vol > 1e-12 ? (m * 12) / vol : NaN
}
netSeries = (r, to, bp) => r.map((x, i) => x - to[i] * bp / 1e4)
wealthPath = (r) => { let w = 1; return r.map((x) => (w *= 1 + x)) }
nberMarks = (nber) => Plot.rectX(nber, { x1: (d) => parseMonth(d.start), x2: (d) => parseMonth(d.end), fill: palette.band })

What this shows. The ordering of the curves is the ordering of gross Sharpe ratios. Costs change levels more than ordering at 10 bp, and at 50 bp the low-turnover rules lose less. The intercept experiment is the large effect; the metric change on its own is a small one. Read the paper page for the argument.
