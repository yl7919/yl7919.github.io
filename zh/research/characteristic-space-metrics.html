SSRN 预印本 · 2026 年 9 月 · DOI 10.2139/ssrn.7445120（SSRN 上署名为 Yang Liu）

两个因子模型可以给出完全相同的拟合收益，却对“收益有多少来自潜在因子、多少来自市场等可观测因子、多少来自截距”给出不同答案。本文证明，这一拆分由衡量特征空间方向所用的“尺子”决定。当这把尺子本身由数据估计时，标准误必须计入它的估计误差；在论文 960 个月的模拟中，若忽略这一误差，名义 95% 置信区间的实际覆盖率只有 89% 至 92%（表 II）。

1 研究问题

基于特征的因子模型在拟合收益时，是什么决定了拟合值在潜在因子、可观测因子与截距之间的划分？这种划分又能被估计得多精确？

IPCA（工具化主成分分析）一类模型让规模、价值、动量等公司特征决定每只股票的因子载荷。当潜在因子与可观测因子、截距同时存在时，潜在因子的变动可以抵消载荷在各模块之间的重新分配，而每一个拟合收益都保持不变（第 1 节）。许多特征还彼此重叠：两个价值信号往往选中同一批股票，这使划分规则的选择变得至关重要。

2 为什么重要

研究者经常报告潜在因子对某个基准的暴露有多大、残余截距有多大、潜在因子张成了哪些特征方向。这些数字都取决于划分方式，而不只取决于拟合值本身。

  • 经济含义。 在拟合收益完全相同的情况下，同一个基准暴露或截距，用一把尺子看很大，换一把尺子看可能很小（命题 1）。
  • 实务含义。 残差平方和与 R² 只依赖拟合值，因此无法在不同尺子之间作出选择（推论 1）。
  • 统计含义。 本文所用的尺子是特征格拉姆（Gram）矩阵的样本均值，它本身由数据估计。把它当作已知，会遗漏度量带来的方差项及其与收益得分的协方差（定理 1）；在论文的模拟中，这会使标准误偏小（第 8.2 节）。

3 论证脉络

  1. 问题。 用什么规则把同一个拟合收益分给潜在因子、可观测因子和截距？→ 研究问题
  2. 动机。 报告的暴露随规则而变，拟合却不变，所以拟合指标无法选定规则。→ 为什么重要
  3. 框架。 特征空间上的内积（即度量）选定这一划分；换一个度量，拟合被重新拆分，但任何拟合收益都不变。→ 理论框架
  4. 机制。 改变度量会在各模块之间挪动拟合收益，而总和不变。度量由同一面板数据估计，其估计误差会传入所报告的暴露，并可能改变暴露上限。→ 一个简单例子
  5. 证据。 真实特征中有相当一部分暴露彼此重叠，谱结构集中；模拟显示，忽略度量误差会降低覆盖率；在需要估计的上限附近，漂移稳健区间能保持覆盖率。→ 研究设计与主要结果
  6. 贡献。 一个计入“尺子”估计误差、且不随模型参数化方式改变的标准误公式；以及在暴露上限附近无论上限是否起约束作用都保持有效的置信区间。→ 与既有文献的比较
  7. 边界。 理论是局部的，假定模型在某个解附近强识别，适用于光滑的报告量。→ 适用范围

4 理论框架

在每一期，股票 i 具有特征 z_{i,t} 和下一期的超额收益。模型包含三个模块（式 2.1）：

r_{i,t+1} = z_{i,t}'\Gamma_\beta f_{t+1} + z_{i,t}'\Gamma_\delta g_{t+1} + z_{i,t}'\Gamma_\alpha + \varepsilon_{i,t+1}.

其中 f 为潜在因子，g 为可观测因子，\Gamma_\alpha 是由特征驱动的截距。要把各模块分开，就必须先规定两个载荷方向何时算“重叠”。格拉姆度量用两个方向在股票上生成的暴露来衡量重叠（式 2.5）：

\langle a,b\rangle_{Q_Z} = a'Q_Z\,b = \mathbb{E}\!\left[N_t^{-1}(Z_t a)'(Z_t b)\right].

两个系数向量在纸面上可以相互垂直，实际却买入同一批股票；按这把尺子衡量，它们是重叠的。

理论分三步展开。

  1. 识别。 对任意正定度量，一个匹配变换先把潜在载荷标准化，再去掉其他模块与潜在方向的重叠，并在因子序列中抵消这两步改动，所有拟合收益保持不变（命题 1）。因此推断对象是去除潜在旋转后的载荷类；总体准则的局部曲率保证它可以被识别（命题 2）。协方差对齐条件（连同局部正则条件）是一个充分条件：即使截面规模固定，它也能保证这一目标就是结构载荷类（命题 3）。
  2. 度量需要估计时的推断。 估计量是精确轮廓化（exactly profiled）的：给定载荷，每期用最小二乘求出因子，各期权重固定。在正则的局部分支上（即某个性质良好的解附近），其 \sqrt{T} 大样本展开在通常的收益项之外加入度量估计项，并保留二者的协方差（定理 1）。光滑的报告量，例如与某一特征方向的对齐程度、与基准子空间的距离、截距暴露，继承同一个影响函数。影响函数刻画每一期数据对估计值的影响；由它可以得到一个不随模型参数化方式改变的抽样误差公式（定理 2）；用标准 HAC（异方差与自相关稳健）方法估计其长期方差，即可得到渐近有效的置信区间（命题 5）。
  3. 需要估计的暴露上限。 模型可以用预算限制截距暴露。在上限附近，估计的度量不仅改变得分，还会移动可行集边界，因此抽样分布是一个投影，而不是对称的正态分布（定理 3）。基于最不利分位数（即在未知松弛程度中取对覆盖率最不利情形下的临界值）构造的区间，在渐近意义下对未知的松弛程度一致地达到至少名义覆盖率，但可能偏保守（定理 4）。当只有一个约束、报告量为标量时，只需计算完全松弛和约束为紧（binding）两种情形（命题 6）。

csm_toy_split = (rho, z) => {
  // identity-ruler section: latent loading on characteristic 1, retained loadings on characteristic 2
  const b = [1, 0], d = [0, 0.6], a = [0, 0.4], f = 1, g = 1
  const M = [[1, rho], [rho, 1]]
  const Mv = (x) => [M[0][0] * x[0] + M[0][1] * x[1], M[1][0] * x[0] + M[1][1] * x[1]]
  const dot = (x, y) => x[0] * y[0] + x[1] * y[1]
  const R = Math.sqrt(dot(b, Mv(b)))                  // eq. 3.2: normalize the latent loading
  const bM = b.map((x) => x / R)
  const cd = dot(bM, Mv(d)), ca = dot(bM, Mv(a))      // eq. 3.3: overlap of retained loadings with the latent span
  const dM = d.map((x, i) => x - bM[i] * cd), aM = a.map((x, i) => x - bM[i] * ca)
  const fM = R * f + cd * g + ca                      // eq. 3.4: offsetting factor adjustment
  return { latent: dot(z, bM) * fM, observed: dot(z, dM) * g, intercept: dot(z, aM), exposure: dot(aM, Mv(aM)) }
}

先把 ρ 拖到零：两把尺子一致，两条形也一样。然后再把它调高。在格拉姆尺子下，第二个价值信号与潜在方向重叠，这部分重叠被划入潜在因子：潜在部分变大，可观测因子和截距部分变小，而拟合收益纹丝不动。再切换到股票 B（账面市值比高、另一价值信号低）：可观测因子与截距部分为负，且随 ρ 增大而更负，潜在部分则变大，总和始终是 0.20。

ρ 越大，截距暴露越小，所以同一个暴露预算可能在一把尺子下接受某个模型，在另一把尺子下却将其排除。在真实数据中，ρ 并非已知，而是由同一面板估计得到；因此这一拆分的每个部分以及截距暴露都带有它的估计误差。图 2 展示忽略这一误差对标准误的影响。

6 研究设计与主要结果

证据分三部分（第 8 节）。第一部分用 1962 年 1 月至 2025 年 12 月、包含 153 个月度特征的美国股票面板，衡量真实特征的重叠程度（第 8.1 节）。第二部分是真值已知的因子面板实验（L = 12 个特征、K = 2 个潜在因子、1 个可观测因子、N = 100 只股票，在 T = 240 和 960 期下各做 2,000 次重复），固定点估计，只比较不同的标准误方法（第 8.2 节）。第三部分用局部实验研究需要估计的暴露上限（第 8.3 节）。

这说明什么。 逐个对特征做排序缩放，并不能消除它们在股票暴露上的重叠。在格拉姆度量下，前五个方向占 37.9% 的谱质量，68 个方向即可达到 90%，而单位矩阵需要 138 个（表 I）。两两特征重叠程度绝对值的中位数为 0.060，第 95 百分位数为 0.380（第 8.1 节）：多数信号彼此不同，但有相当一部分明显重叠。最大与最小特征值之比为 2,339，说明某些特征组合在股票之间几乎不产生独立的变化（表 I）。正是在这种环境下，归因可能随尺子而变（第 8.1 节）。谱结构刻画的是特征暴露，而不是被定价风险的个数。

7 与既有文献的比较

因子模型推断通常用一个标准化约束固定旋转与尺度。本文追问：当这一标准化所依赖的度量需要由数据估计时，它会如何影响潜在因子、可观测因子与截距模块之间的划分。

既有研究 已有结论 本文的补充
Bai (2003)；Bai and Ng (2013) 在标准化约束下，为大维近似因子模型建立识别与推断理论。 以度量为索引、并保留可观测因子与截距模块的载荷类，允许截面规模固定的 \sqrt{T} 理论，并给出协方差对齐条件，使轮廓化目标与结构载荷类一致。
Kelly 等 (2019) 以特征作为潜在因子时变载荷的工具变量（IPCA），模型包含由特征决定的截距与可选的可观测因子；旋转由欧氏标准化 Γβ′Γβ = I 固定。 把这一标准化视为度量的一种选择，说明潜在因子、可观测因子与截距之间的划分取决于该选择，并把估计出的格拉姆度量纳入推断。
Newey (1994)；Newey and McFadden (1994) 为使用第一步估计量的两步估计提供影响函数修正。 把两步修正用于一个既决定分解、又进入报告量的度量，同时保留交叉协方差与坐标不变性。
Geyer (1994)；Andrews (1999)；Shapiro (2000) 参数受约束或位于边界附近时估计量的极限分布。 边界本身通过同一度量被估计，由此得到得分、边界与报告量的联合极限分布。
Andrews and Guggenberger (2009)；Andrews and Soares (2010) 矩不等式可能为紧时的一致有效推断：插入式（最不利）临界值与子抽样，以及用数据挑选接近为紧的不等式的广义矩选择法。 在单一光滑约束和标量报告量下，最不利包络只需内点与紧约束两个端点，无需估计松弛程度，也无需搜索漂移网格。
Li (2025) 一种快速自助法，可逐点一致地估计约束估计量（约束固定或需估计）的极限分布。 当被估计的约束与估计对象共用同一个学习得到的度量时，给出对局部松弛程度一致有效的解析投影方法。

本文的切入点是度量问题，而不是提出新的预测变量。矩阵流形上的几何 (Edelman 等 1998)、两步估计修正和约束投影都是成熟工具；本文的贡献在于把它们结合起来，处理同一个对象：一种分解，其度量规则由同一数据估计，并可能同时设定暴露上限。由此得到的影响函数在任何容许的局部坐标下结果相同；对单一光滑约束和标量报告量，在需要估计的上限附近，所给区间无需事先判断约束是否为紧，代价是区间偏保守、更长。

关于同一识别问题更早、范围更广的论述，见《基于特征的因子模型中识别问题的几何框架》。配套论文《特征几何与投资组合选择》把匹配变换的结论应用于投资组合。

8 适用范围

  • 理论是局部的、有限维的：依赖正则的局部分支、精确轮廓化的固定权重估计量和光滑的报告量（第 9 节）。弱识别、特征维数增长以及未经验证的交替算法，均不在本文讨论范围之内（第 7.4 节与第 9 节）。
  • 关于报告量的推断定理并不适用于滚动投资组合的夏普比率或风险溢价。
  • 模拟中的改进在于同一估计量的不确定性度量更准确，而不是拟合收益更好（第 8.2 节）。
  • 边界结果只针对单一光滑约束和标量报告量，不涵盖多个不等式约束或向量置信域（第 7.3 节）。
  • 截距是拟合收益中未归入因子模块的部分；要把它解读为定价误差，需要先设定一个定价模型（第 2 节）。
